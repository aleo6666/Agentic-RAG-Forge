# RAG Forge 前端说明

RAG Forge 提供了一个基于 Vue 3 构建的 Web 控制台，包含三个页面：

1. 对话页：支持 Agentic 与标准两种问答模式，Agentic 模式会展示完整的决策轨迹，包括意图路由、混合检索、相关性评分、查询改写、答案自检等步骤，所有决策均可审计。
2. 知识库页：支持拖拽上传文档，上传后自动完成解析、切分、向量化并入库，可以查看每个文档的 chunk 数量和字符数，也可以一键清空整个知识库。
3. 系统页：展示服务健康状态、LLM 与 Embedding 的配置信息，以及 Agentic RAG 的核心能力说明。

前端构建产物存放在 frontend/dist 目录，由 FastAPI 在同一个端口托管，单端口即可完成部署。

上传支持 Markdown、纯文本、PDF 等格式，多租户环境下每个租户的知识库完全隔离。
